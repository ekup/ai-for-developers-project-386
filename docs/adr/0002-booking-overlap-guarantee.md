# Гарантия отсутствия пересечений записей на уровне хранилища

**Статус**: accepted

Две записи не должны пересекаться по времени, даже если относятся к разным типам событий. Отклонена очевидная реализация «проверить занятость запросом, затем вставить»: между проверкой и вставкой гонка двух запросов создаёт двойную запись. Вместо этого проверка и вставка выполняются в одной транзакции SQLite (`BEGIN IMMEDIATE`); дополнительно соединение ограничено `MaxOpenConns(1)`, что сериализует запись.
