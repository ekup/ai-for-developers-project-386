# Мягкое удаление типов событий

**Статус**: accepted

У типа события могут быть уже созданные записи, а жёсткое удаление уничтожило бы историю встреч. Поэтому удаление помечает тип как удалённый (`deleted_at`): тип пропадает из гостевого списка, но существующие записи сохраняются и остаются видимыми владельцу в предстоящих встречах. Альтернатива — запрещать удаление при наличии записей — отвергнута: владелец не смог бы убрать устаревший тип, не отменяя встречи.
