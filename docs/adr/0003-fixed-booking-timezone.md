# Фиксированный пояс записи вместо пояса хоста

**Статус**: accepted

Рабочие часы, окно записи и начало записей система понимает в одном поясе, и он выбран продуктово — `Europe/Moscow`, а не «тот, что окажется у сервера». На Render сервер живёт в UTC, и пояс хоста сдвигал бы рабочее окно 09:00–18:00 и переключал «сегодня» в 03:00 по Москве. Пояс задаётся переменной окружения `TZ` (прод — `render.yaml`, dev — `make dev-backend`), а в runtime-образ добавлен пакет `tzdata`: без него `TZ` молча игнорируется и alpine остаётся в UTC. Альтернатива — отдельный параметр конфигурации вместо `TZ` — отвергнута: стандартную переменную уже читает пакет `time`, лишняя сущность не нужна. Браузер время не пересчитывает, см. `GLOSSARY.md`, термин «Пояс записи».
